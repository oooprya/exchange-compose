# Система управления двумя кассами (Касса + Сейф)

## 📋 Обзор

Система позволяет управлять двумя независимыми кассами на одной точке обмена:
- **🏪 Касса (Desk)** - основная рабочая касса
- **🔐 Сейф (Safe)** - безопасное хранилище для больших сумм

## 🎯 Функциональность

### 1. **Просмотр баланса кассы и сейфа**

Справа на странице заказов находится панель **"💰 Кассы"** с четырьмя вкладками:

- **🏪 Касса** - текущий баланс рабочей кассы
- **🔐 Сейф** - текущий баланс сейфа  
- **⚖️ Итого** - сравнение балансов обеих касс по всем валютам
- **📅 На утро** - баланс на начало смены

### 2. **Перевод денег между кассой и сейфом**

#### Способ 1: Через кнопку "Перевести"
1. Откройте вкладку **"⚖️ Итого"** в панели баланса
2. Нажмите кнопку **"💸 Перевести между кассами"**
3. Заполните форму:
   - **Откуда:** Выберите исходную кассу (Касса или Сейф)
   - **Куда:** Выберите целевую кассу (противоположная выберется автоматически)
   - **Валюта:** Выберите валюту для перевода
   - **Сумма:** Введите сумму перевода
   - **Комментарий:** (опционально) Причина перевода
4. Нажмите **"Перевести"**

#### Способ 2: Клик по валюте
1. Откройте вкладку **"🏪 Касса"** или **"🔐 Сейф"**
2. Кликните на любую валюту
3. Откроется модальное окно с предзаполненной исходной кассой
4. Завершите заполнение формы

### 3. **Отслеживание операций**

Все операции перевода записываются в историю как:
- **Из кассы:** Расход (Out)
- **В кассу:** Приход (In)

История операций видна в истории движений (CashMovement).

## 🔒 Безопасность

- Система проверяет наличие достаточных средств перед переводом
- Невозможно перевести больше, чем доступно
- Все операции выполняются атомарно (либо полностью выполнены, либо полностью откачены)
- Операции логируются с комментариями

## 📊 Особенности

### Автоматические проверки:
- ✅ Проверка наличия валюты в исходной кассе
- ✅ Проверка достаточности средств
- ✅ Проверка что выбраны разные кассы
- ✅ Проверка коректности суммы (> 0)

### Отображение информации:
- Баланс кассы в **синем** цвете 🏪
- Баланс сейфа в **зеленом** цвете 🔐
- Доступная сумма отображается в реальном времени при выборе валюты

## 🚀 Примеры использования

### Пример 1: Защита наличности
Клиент принес большую сумму USD. Кассир принял ее в кассу, но решил переместить в сейф:
1. В панели баланса выбирает **"⚖️ Итого"**
2. Нажимает **"💸 Перевести между кассами"**
3. Откуда: Касса → Куда: Сейф → Валюта: USD → Сумма: 1000
4. Комментарий: "Защита наличности"
5. Нажимает **"Перевести"**

### Пример 2: Пополнение кассы для работы
Смена закончилась, кассира нужно пополнить для следующей смены:
1. Выбирает **"🔐 Сейф"** 
2. Кликает на нужную валюту (например EUR)
3. Откроется форма с Сейфом как источником
4. Меняет на: Касса → Вводит сумму
5. Нажимает **"Перевести"**

## ⚙️ Техническая информация

### Структура данных

Система использует существующие модели:
- `CashNode` - с типами "desk" и "safe"
- `CashBalance` - баланс каждой кассы по валютам
- `CashMovement` - история движения денег

### API Endpoint

`POST /admin/wholesale/transfer-between-desks/`

**Параметры:**
```json
{
  "from_node_type": "desk|safe",
  "to_node_type": "desk|safe", 
  "currency_code": "USD",
  "amount": 1000.00,
  "comment": "Причина перевода",
  "shift_id": 123
}
```

**Ответ (успех):**
```json
{
  "success": true,
  "message": "Успешно переведено 1000.00 USD из Касса в Сейф"
}
```

**Ответ (ошибка):**
```json
{
  "success": false,
  "error": "Недостаточно USD. Доступно: 500.00"
}
```

## 🛠️ Настройка

### Требования
- Две кассы (CashNode) с типами `desk` и `safe` на одной точке обмена
- Доступные валюты должны быть созданы в системе

### Создание касс (если их нет)
1. Перейти в Admin → Кассы или машины (Wholesale)
2. Создать две кассы:
   - Имя: "Касса", Тип: "desk"
   - Имя: "Сейф", Тип: "safe"
3. Назначить обе кассы сотруднику в профиле

### Инициализация баланса
1. Перейти в Admin → Балансы касс
2. Создать записи CashBalance для каждой кассы и валюты
3. Установить начальные балансы

## 📝 Советы

1. **Регулярные переводы:** Переводите крупные суммы в сейф после каждого клиента
2. **Комментарии:** Всегда добавляйте комментарий о причине перевода для аудита
3. **Проверка остатков:** Используйте вкладку "⚖️ Итого" для быстрой проверки общего баланса
4. **Утренние балансы:** Слепок на начало смены сохраняется автоматически при открытии смены

## ❓ Часто задаваемые вопросы

**Q: Что произойдет если я ошибусь в сумме?**
A: Вы можете сделать обратный перевод. Система позволяет совершать неограниченное количество переводов.

**Q: Видны ли операции перевода в отчете смены?**
A: Да, они записываются как операции движения средств и влияют на финансовый результат смены.

**Q: Может ли кассир переводить деньги между точками обмена?**
A: Нет, система работает только с двумя кассами на одной точке обмена.

**Q: Что если в сейфе нет нужной валюты?**
A: Система автоматически создаст баланс при первом переводе.

## 📞 Поддержка

При возникновении проблем:
1. Проверьте что обе кассы активны (`is_active=True`)
2. Убедитесь что у вас есть достаточно средств
3. Проверьте что валюта существует в системе
4. Посмотрите логи Django сервера для деталей ошибки
